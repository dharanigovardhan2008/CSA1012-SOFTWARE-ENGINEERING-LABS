# Experiment 12 – Prioritize Task Management System Requirements using MoSCoW and Kano Models in Jira

## Aim

To prioritize the functional requirements of a Task Management System using the **MoSCoW** and **Kano** prioritization models in Jira for effective requirement analysis and sprint planning.

---

## Problem Statement

A small team plans to develop a **Task Management System** to efficiently manage tasks, assign responsibilities, monitor progress, and improve team collaboration. To ensure that the most valuable features are implemented first, the project requirements must be prioritized using software engineering techniques.

Using **Jira**, create the project requirements and classify them according to both the **MoSCoW** and **Kano** models. The prioritization should help identify essential, desirable, and optional features while considering customer satisfaction and business value.

---

## Objectives

- Understand requirement prioritization techniques.
- Learn the MoSCoW prioritization model.
- Understand the Kano model for customer satisfaction.
- Create and manage project requirements in Jira.
- Prioritize requirements for efficient sprint planning.

---

## Requirements

Create Jira issues for the following features:

1. User Login and Role Assignment
2. Task Creation and Assignment
3. Task Prioritization and Deadlines
4. Progress Tracking and Reporting

Categorize each requirement using:

### MoSCoW Model

- Must Have
- Should Have
- Could Have
- Won't Have

### Kano Model

- Basic (Must-be)
- Performance
- Excitement

Document the prioritization for each requirement within Jira using labels, custom fields, or issue descriptions.

---

## Sample Prioritization

| Requirement | MoSCoW | Kano |
|-------------|---------|------|
| User Login and Role Assignment | Must Have | Basic (Must-be) |
| Task Creation and Assignment | Must Have | Performance |
| Task Prioritization and Deadlines | Should Have | Performance |
| Progress Tracking and Reporting | Could Have | Excitement |

---

## Tools Required

- Jira Software

---

## Expected Outcome

A Jira project containing the Task Management System requirements successfully prioritized using both the **MoSCoW** and **Kano** models, enabling effective requirement management and sprint planning.
