# Experiment 11 – Integrate Jira Tasks with Confluence for Library Management System

## Aim

To integrate Jira with Confluence by embedding Jira issues into a Confluence page, enabling efficient task tracking, progress monitoring, and collaboration during the development of the Library Management System.

---

## Problem Statement

Project management tools such as Jira and Confluence help development teams collaborate efficiently by managing tasks and documenting project information in one place. Integrating Jira with Confluence allows project stakeholders to monitor sprint progress, view task status, and access project documentation without switching between applications.

Using **Jira** and **Confluence**, create a project overview page for the **Library Management System** and perform the following tasks:

- Create a Confluence page titled **"Library Management System Project Overview."**
- Embed at least **five Jira issues** related to the project.
- Display the Jira issues using the **Jira Macro** with their current status.
- Add a progress bar to represent the overall completion of the sprint tasks.
- Capture a screenshot of the completed Confluence page.

---

## Objectives

- Understand the integration between Jira and Confluence.
- Learn how to embed Jira issues into Confluence pages.
- Monitor sprint progress using Jira macros.
- Visualize project completion using a progress bar.
- Improve project documentation and collaboration.

---

## Requirements

Perform the following tasks:

1. Create a Confluence page titled:
   - **Library Management System Project Overview**

2. Create or use at least five Jira issues such as:
   - Develop Book Search Functionality
   - Create User Login Page
   - Implement Book Reservation Module
   - Develop Email Notification Feature
   - Design Librarian Dashboard

3. Embed the Jira issues using the **Jira Macro**.

4. Display the issue status, such as:
   - To Do
   - In Progress
   - Done

5. Add a progress bar showing the percentage of completed tasks in the sprint.

6. Capture a screenshot of the completed Confluence page.

---

## Tools Required

- Jira Software
- Atlassian Confluence

---

## Expected Outcome

A Confluence page successfully integrated with Jira, displaying embedded Jira issues, their current status, and a progress bar representing the completion percentage of the Library Management System sprint.
