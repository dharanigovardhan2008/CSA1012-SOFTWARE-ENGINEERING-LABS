# Experiment 07 – Design UML Diagrams for an Online Security Management System

## Aim

To analyze the requirements of an Online Security Management System and design the UML diagrams, namely the Class Diagram, Use Case Diagram, and Activity Diagram, using the Umbrello tool.

---

## Problem Statement

A college employs a large number of security personnel who are assigned duties at various locations across the campus. Each security person follows a duty schedule that includes the date, duty start time, duty end time, and assigned location, ensuring that every campus location is covered. If a security person takes leave, it is recorded manually, and at the end of each month, salaries are calculated based on duties performed and leaves taken.

Since manual handling of duty allocation, leave management, and salary calculation is time-consuming and complex, the college plans to develop an **Online Security Management System** to automate these activities.

Using the **Umbrello** tool, design the following UML diagrams for the Online Security Management System:

- Class Diagram
- Use Case Diagram
- Activity Diagram

The Class Diagram should represent the relevant classes, their attributes, methods, and relationships. The Use Case Diagram should illustrate the interactions between users and the system. The Activity Diagram should describe the workflow from duty assignment to salary generation.

---

## Objectives

- Understand the fundamentals of UML modeling.
- Identify the actors and functional requirements of the system.
- Design a Class Diagram representing the system structure.
- Create a Use Case Diagram to model user interactions.
- Develop an Activity Diagram to represent the overall workflow.

---

## Requirements

### 1. Class Diagram

Include classes such as:

- Security Personnel
- Duty Schedule
- Leave Request
- Campus Location
- Salary
- Administrator
- Attendance
- Payroll

Include appropriate:

- Attributes
- Methods
- Relationships (Association, Aggregation, Composition, Inheritance)

---

### 2. Use Case Diagram

Actors:

- Administrator
- Security Personnel
- Payroll Officer

Sample Use Cases:

- Login
- Assign Duty
- View Duty Schedule
- Apply for Leave
- Approve Leave
- Record Attendance
- Manage Campus Locations
- Calculate Salary
- Generate Salary Report
- Logout

---

### 3. Activity Diagram

Workflow:

1. User Login
2. Assign Security Duty
3. View Duty Schedule
4. Security Performs Duty
5. Apply for Leave (if required)
6. Record Attendance
7. Calculate Monthly Salary
8. Generate Salary Report
9. Logout

---

## Tools Required

- Umbrello UML Modeller

---

## Expected Outcome

A complete UML model of the Online Security Management System consisting of a Class Diagram, Use Case Diagram, and Activity Diagram that accurately represents the system's structure, user interactions, and workflow.
