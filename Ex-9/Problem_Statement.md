# Experiment 09 – Create a Scrum Project in Jira

## Aim

To understand the Scrum framework by creating and managing a Scrum project in Jira, including backlog creation, sprint planning, task prioritization, and sprint execution.

---

## Problem Statement

Scrum is an Agile project management framework that helps teams develop, deliver, and maintain complex projects through iterative development. It organizes work into short iterations called sprints, allowing teams to prioritize tasks, track progress, and deliver value efficiently.

Using **Jira**, create a Scrum project and perform the following activities:

- Create a product backlog with at least five user stories or tasks.
- Prioritize the backlog based on importance.
- Create a one-week sprint.
- Move the backlog items into the sprint.
- Start the sprint.
- Display the sprint board at the beginning and after completing the sprint.

---

## Objectives

- Understand the Scrum framework and Agile methodology.
- Learn how to create and manage a Scrum project in Jira.
- Create and prioritize a product backlog.
- Plan and execute a sprint.
- Track the progress of tasks using the Scrum Board.

---

## Requirements

Perform the following tasks in Jira:

1. Create a Scrum Project.
2. Add at least five backlog items.
3. Prioritize the backlog.
4. Create a Sprint with a duration of one week.
5. Move the backlog items into the sprint.
6. Start the sprint.
7. Capture the Sprint Board at the start of the sprint.
8. Move tasks through the workflow (To Do → In Progress → Done).
9. Capture the Sprint Board after completing the sprint.

---

## Sample Backlog Items

- Create User Registration Page
- Develop Login API
- Create Database Tables
- Design Home Page
- Test Login Functionality

---

## Tools Required

- Jira Software

---

## Expected Outcome

A Scrum project successfully created in Jira with a prioritized backlog, a one-week sprint, and sprint execution demonstrated through the Sprint Board before and after task completion.
