# Experiment 10 – Prioritize Library Management System Requirements using the MoSCoW Method

## Aim

To prioritize the functional requirements of a Library Management System using the MoSCoW prioritization technique based on user impact, stakeholder needs, and project feasibility, and document the results in a Google Sheet or Microsoft Excel file.

---

## Problem Statement

A Library Management System is designed to automate the management of library resources and improve the overall experience for both librarians and users. The system should provide features that support book searching, reservation, notifications, reporting, and other advanced functionalities.

Using the **MoSCoW Method**, categorize the following requirements into:

- Must Have
- Should Have
- Could Have
- Won't Have

The prioritization should be based on:

- Impact on users and stakeholders.
- Feasibility considering time, budget, and resource constraints.

The final categorized requirements along with their justification should be documented in a **Google Sheet or Microsoft Excel** file.

---

## Objectives

- Understand requirement prioritization techniques.
- Learn the MoSCoW prioritization model.
- Analyze functional requirements based on business value.
- Categorize requirements according to project constraints.
- Document the prioritized requirements in a spreadsheet.

---

## Requirements

Categorize the following requirements using the MoSCoW Method:

1. Search books by title and author.
2. Online book reservation system.
3. Monthly reports on borrowed books for administrators.
4. Email notifications for overdue books.
5. QR code scanning for borrowing and returning books.
6. User-friendly dashboard for librarians.
7. Review and rating system for books.
8. Chatbot for user assistance.
9. Mobile application for the system.
10. Multi-language support.

For each requirement, provide:

- MoSCoW Category
- Justification based on:
  - User and stakeholder impact.
  - Feasibility considering time, budget, and available resources.

---

## Tools Required

- Google Sheets or Microsoft Excel

---

## Expected Outcome

A well-organized spreadsheet containing all Library Management System requirements categorized using the MoSCoW Method, along with appropriate justifications based on stakeholder impact and project feasibility.
