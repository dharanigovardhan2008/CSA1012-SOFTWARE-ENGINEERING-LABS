# Experiment 21 – Containerize a Python Flask Application Using Docker

## Aim

To develop a simple Python Flask "To-Do" application, containerize it using Docker, build and run the Docker container locally, test its functionality, and publish the Docker image to Docker Hub.

---

## Problem Statement

Containerization enables applications to run consistently across different computing environments by packaging the application along with its dependencies. Docker simplifies the deployment process by creating lightweight, portable containers. Flask is a lightweight Python web framework that is commonly used for developing web applications and REST APIs.

In this experiment, develop a simple Flask-based "To-Do" application, create a Dockerfile to containerize the application, build and run the Docker container locally, verify its functionality, and push the Docker image to Docker Hub.

---

## Objectives

- Understand the basics of Flask web application development.
- Learn Docker containerization concepts.
- Create a Dockerfile for a Flask application.
- Build and run Docker containers.
- Test the application inside a Docker container.
- Publish Docker images to Docker Hub.

---

## Requirements

Perform the following tasks:

1. Develop a simple Python Flask application for managing a "To-Do" list.
2. Create a `Dockerfile` to containerize the Flask application.
3. Build the Docker image.
4. Run the Docker container locally.
5. Test the application's functionality using a web browser or API testing tool.
6. Push the Docker image to Docker Hub.
7. Submit the Dockerfile and screenshots of the testing results.
