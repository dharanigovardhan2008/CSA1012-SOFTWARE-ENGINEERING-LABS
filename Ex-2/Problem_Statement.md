# Experiment 02 – Sketch a Simple Prototype of a Bus Ticket Booking System using Figma

## Aim

To design a simple and user-friendly prototype of a Bus Ticket Booking System using the Figma design tool.

---

## Problem Statement

Design a prototype for a **Bus Ticket Booking System** using Figma. The prototype should provide an intuitive interface that allows users to search for buses, select seats, make bookings, and confirm ticket reservations.

The design should focus on usability, simplicity, and a smooth user experience.

---

## Objectives

- Learn the basics of UI/UX design using Figma.
- Design an interactive prototype for a Bus Ticket Booking System.
- Create an easy-to-use interface for users.
- Understand the workflow of designing application screens.

---

## Requirements

Design the following screens in Figma:

1. Welcome / Login Screen
2. Home Screen
3. Search Bus Screen
4. Bus List Screen
5. Seat Selection Screen
6. Passenger Details Screen
7. Payment Screen
8. Booking Confirmation Screen

---

## Tools Required

- Figma

---

## Expected Outcome

A simple and interactive prototype of a Bus Ticket Booking System that demonstrates the complete booking process from searching buses to confirming tickets.
