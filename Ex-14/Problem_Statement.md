# Experiment 14 – Collaborate on a GitHub Project using the Fork and Pull Request Workflow

## Aim

To understand and demonstrate collaborative software development using Git and GitHub by following the Fork and Pull Request workflow.

---

## Problem Statement

GitHub provides a collaborative environment for software development through version control and code review. The Fork and Pull Request workflow enables developers to contribute to open-source and team projects without directly modifying the original repository. This workflow includes forking a repository, creating a feature branch, making changes, submitting a pull request, reviewing feedback, and merging approved changes.

Using **Git** and **GitHub**, demonstrate the complete Fork and Pull Request workflow by performing the following tasks.

---

## Objectives

- Understand distributed version control using Git.
- Learn the Fork and Pull Request workflow.
- Create and manage branches.
- Commit and push changes to GitHub.
- Create and review Pull Requests.
- Collaborate with other developers using GitHub.

---

## Requirements

Perform the following tasks:

1. Fork an existing public GitHub repository.
2. Clone the forked repository to the local machine.
3. Create a new feature branch.
4. Modify the project by:
   - Adding a new function,
   - Fixing a bug, or
   - Updating the README file.
5. Commit the changes with an appropriate commit message.
6. Push the feature branch to GitHub.
7. Create a Pull Request from the feature branch to the main branch.
8. Review the Pull Request and provide feedback.
9. Make additional commits if changes are requested.
10. Merge the Pull Request after approval.
11. Submit the Pull Request link along with a summary of the work completed.

---

## Tools Required

- Git
- GitHub
- Visual Studio Code (or any code editor)

---

## Deliverables

- Forked GitHub Repository
- Feature Branch
- Pull Request
- Pull Request Link
- Summary of Changes
- Screenshot of Pull Request (optional)

---

## Expected Outcome

A successful demonstration of collaborative software development using the Git Fork and Pull Request workflow. The project should include a completed Pull Request, merged changes, and documentation summarizing the contribution and collaboration process.
