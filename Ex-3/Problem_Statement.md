# Experiment 03 – Create a Prototype for an E-Commerce Mobile App using Figma

## Aim

To design an interactive prototype of an E-Commerce Mobile Application using Figma that addresses conflicting stakeholder requirements and helps gather feedback for design improvements.

---

## Problem Statement

The stakeholders of an E-Commerce Mobile Application have different opinions regarding the user interface design. Create a prototype using Figma to present multiple screens of the application, allowing stakeholders to review the design, provide feedback, and approve the final user interface.

The prototype should focus on creating an intuitive, visually appealing, and user-friendly shopping experience.

---

## Objectives

- Understand the UI/UX design process.
- Create a prototype using Figma.
- Resolve stakeholder conflicts through visual representation.
- Collect stakeholder feedback for design refinement.
- Improve usability and user experience.

---

## Requirements

Design the following screens in Figma:

1. Splash Screen
2. Login / Sign Up Screen
3. Home Screen
4. Product Categories Screen
5. Product Details Screen
6. Shopping Cart Screen
7. Checkout Screen
8. Order Confirmation Screen

---

## Tools Required

- Figma

---

## Expected Outcome

An interactive prototype of an E-Commerce Mobile Application that effectively demonstrates the user flow and provides stakeholders with a clear visualization for feedback and approval.
