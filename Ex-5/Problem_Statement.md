# Experiment 05 – Lexicographically Smallest String using Character Swapping in Raptor

## Aim

To design and validate a flowchart using the Raptor tool that finds the lexicographically smallest string by swapping two characters in a given lowercase English alphabet string at most once.

---

## Problem Statement

Given a string consisting of lowercase English alphabets, two distinct characters can be selected, and all occurrences of the first character are replaced with the second character, while all occurrences of the second character are replaced with the first character. This swapping operation can be performed at most once.

Using the **Raptor** tool, design and validate a flowchart that determines the lexicographically smallest string that can be obtained after performing the character swap operation.

---

## Objectives

- Understand string manipulation techniques.
- Learn the concept of lexicographical ordering.
- Design and validate algorithms using Raptor.
- Perform character replacement and string transformation.
- Generate the lexicographically smallest possible string.

---

## Requirements

The flowchart should perform the following operations:

1. Start the program.
2. Accept a lowercase string as input.
3. Identify two characters whose swap results in the smallest lexicographical string.
4. Swap all occurrences of the selected characters.
5. Display the resulting lexicographically smallest string.
6. Stop the program.

---

## Tools Required

- Raptor

---

## Expected Outcome

A validated Raptor flowchart that accepts a lowercase string, performs at most one character swap, and displays the lexicographically smallest string obtained after the operation.
