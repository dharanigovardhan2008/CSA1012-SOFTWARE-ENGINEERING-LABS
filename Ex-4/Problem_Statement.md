# Experiment 04 – Display the Total Number of Characters in a String using Raptor

## Aim

To design a flowchart using the Raptor tool that accepts a string as input, calculates the total number of characters present in the string, and displays the length of the string.

---

## Problem Statement

A string is a sequence of characters enclosed within double quotes (" "). Strings are immutable, meaning that any modification to a string results in the creation of a new string. If a collection of characters needs to be modified, a character array can be used instead. String handling provides various methods to perform operations such as searching, comparing, and finding the length of a string.

Using the **Raptor** tool, design a flowchart that accepts a string from the user, determines the total number of characters in the string, and displays the character count.

---

## Objectives

- Understand the concept of strings and string handling.
- Learn how to accept string input in Raptor.
- Calculate the total number of characters in a string.
- Display the length of the entered string.

---

## Requirements

The flowchart should perform the following operations:

1. Start the program.
2. Accept a string from the user.
3. Determine the length of the string.
4. Display the total number of characters.
5. Stop the program.

---

## Tools Required

- Raptor

---

## Expected Outcome

A Raptor flowchart that successfully accepts a string as input, calculates the total number of characters in the string, and displays the result.
