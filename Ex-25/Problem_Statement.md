# Experiment 25 – Create and Manage a GitHub Repository

## Aim

To create a new GitHub repository, initialize it with a README.md file, clone it to a local machine, update the README.md file, and push the changes back to GitHub using Git version control.

---

## Problem Statement

GitHub is a widely used platform for hosting and managing software projects using Git version control. It enables developers to create repositories, track changes, collaborate efficiently, and maintain project documentation. One of the first steps in any software project is creating a repository, initializing it with a README file, cloning it locally, making changes, and pushing those changes back to GitHub.

In this experiment, create a new GitHub repository for a personal project, initialize it with a **README.md** file, clone the repository to the local machine, edit the README file by adding a project description, and push the updated changes back to GitHub.

---

## Objectives

- Understand Git and GitHub basics.
- Create a new GitHub repository.
- Clone a remote repository to a local machine.
- Edit and update the README.md file.
- Stage, commit, and push changes using Git.
- Verify changes in the remote GitHub repository.

---

## Requirements

Perform the following tasks:

1. Create a new GitHub repository for a personal project.
2. Initialize the repository with a **README.md** file.
3. Clone the repository to your local machine.
4. Edit the **README.md** file by adding a project description.
5. Stage the modified file.
6. Commit the changes with an appropriate commit message.
7. Push the changes to the GitHub repository.
8. Verify that the updated README file is available on GitHub.

---

## Tools Required

- Git
- GitHub
- Visual Studio Code (or any text editor)
- Git Bash / Terminal

---

## Files Required

- README.md

---

## Sample Git Commands

### Clone Repository

```bash
git clone https://github.com/<username>/<repository-name>.git
```

### Navigate to Repository

```bash
cd <repository-name>
```

### Check Repository Status

```bash
git status
```

### Stage Changes

```bash
git add README.md
```

### Commit Changes

```bash
git commit -m "Updated README with project description"
```

### Push Changes

```bash
git push origin main
```
