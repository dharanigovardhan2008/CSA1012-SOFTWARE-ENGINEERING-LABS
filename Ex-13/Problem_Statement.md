# Experiment 13 – Prioritize Online Learning Platform Requirements using MoSCoW and Kano Models in Jira

## Aim

To prioritize the functional requirements of an Online Learning Platform using the **MoSCoW** and **Kano** prioritization techniques in Jira for effective project planning and requirement management.

---

## Problem Statement

An Online Learning Platform is being developed to provide students with an engaging and interactive learning experience. The platform includes features such as course enrollment, video lectures, quizzes, progress tracking, discussion forums, and certificate generation. To ensure efficient project execution, these requirements must be prioritized based on business value, user satisfaction, and development feasibility.

Using **Jira**, create the project requirements and categorize them using both the **MoSCoW** and **Kano** models.

---

## Objectives

- Understand requirement prioritization techniques.
- Apply the MoSCoW prioritization model.
- Apply the Kano model for customer satisfaction analysis.
- Create and manage requirements using Jira.
- Improve sprint planning and feature prioritization.

---

## Requirements

Create Jira issues for the following functionalities:

1. Course Enrollment and Registration
2. Video Lecture Streaming
3. Interactive Quizzes and Assignments
4. Progress Tracking Dashboard
5. Peer-to-Peer Discussion Forums
6. Certificate Generation

Categorize each requirement using:

### MoSCoW Model

- Must Have
- Should Have
- Could Have
- Won't Have

### Kano Model

- Basic (Must-be)
- Performance
- Excitement

Record the prioritization in Jira using issue descriptions, labels, or custom fields.

---

## Sample Prioritization

| Requirement | MoSCoW | Kano |
|-------------|---------|------|
| Course Enrollment and Registration | Must Have | Basic (Must-be) |
| Video Lecture Streaming | Must Have | Performance |
| Interactive Quizzes and Assignments | Should Have | Performance |
| Progress Tracking Dashboard | Should Have | Performance |
| Peer-to-Peer Discussion Forums | Could Have | Excitement |
| Certificate Generation | Could Have | Excitement |

---

## Tools Required

- Jira Software

---

## Expected Outcome

A Jira project containing the Online Learning Platform requirements, successfully categorized and prioritized using the **MoSCoW** and **Kano** models to support effective requirement management, sprint planning, and product development.
