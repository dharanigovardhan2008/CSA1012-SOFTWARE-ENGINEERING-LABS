# Experiment 26 – Clone an Existing GitHub Repository and Modify a File

## Aim

To learn the basic Git workflow by cloning an existing GitHub repository, making modifications to a file, and saving the changes on the local machine.

---

## Problem Statement

Git is a distributed version control system that enables developers to manage source code efficiently and collaborate on software projects. Cloning a repository creates a local copy of the remote project, allowing developers to view, edit, and test the code before committing and sharing changes.

In this experiment, select an existing public GitHub repository, clone it to the local machine using Git, navigate to the project directory, modify one of the files, and save the changes. This exercise demonstrates the initial steps involved in working with Git repositories.

---

## Objectives

- Understand the purpose of cloning a Git repository.
- Learn how to use the `git clone` command.
- Navigate through a local Git repository.
- Edit an existing project file.
- Save modifications locally.

---

## Requirements

Perform the following tasks:

1. Choose an existing public GitHub repository.
2. Clone the repository to your local machine using the `git clone` command.
3. Navigate to the cloned repository directory.
4. Open one of the existing files using a text editor or IDE.
5. Make a small modification, such as:
   - Editing a line of text.
   - Fixing a spelling mistake.
   - Updating documentation.
6. Save the modified file.
7. Verify that the file has been updated successfully.

---

## Tools Required

- Git
- GitHub
- Visual Studio Code (or any text editor)
- Git Bash / Terminal

---

## Files Required

- Existing project files
- README.md (or any editable file)

---

## Sample Git Commands

### Clone Repository

```bash
git clone https://github.com/<username>/<repository-name>.git
```

### Navigate to Repository

```bash
cd <repository-name>
```

### Check Repository Status

```bash
git status
```
